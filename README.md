# Meeting@10 Assets Repository

Generated 3D primitives, abstract sculptural shapes, brand emblems, and visual assets for Meeting@10 and the ACCS (Access for College of Computer Studies) design system.

## Overview
- **Total Asset Batches**: 85 distinct batches
- **Total Isolated PNG Assets**: 832+ assets rendered on solid `#FFFFFF` backgrounds for cutout / transparency keying.
- **Formats**: High-resolution PNGs, contact sheets (`preview.jpg`), and batch archives (`.zip`).
- **Research**: [`qcu-college-of-computer-studies-research.md`](./qcu-college-of-computer-studies-research.md) sourced via local Firecrawl CLI.

## Key Asset Collections
- **ACCS Linked-C Brand Emblems**: Standalone sculptural 3D marks (Frosted Acrylic, Chrome Cobalt, Ribbon, Faceted Crystal, Neon Glass, Folded Paper, Wireframe, Liquid Glass) under `accs-primitives-linked-c-20261028/`.
- **IT & Computer Studies Identity**: Microchips, neural graph spheres, cipher rings, and glowing data conduits under `accs-floating-it-20261028/`.
- **Institutional Badges & Seals**: Algorithmic laurel crests, binary wreaths, and faceted academic shields under `accs-symbols-institutional-20261028/`.
- **Functional UI Primitives**: 3D cursor arrows, locator prisms, floating cloud nodes, and network gateways under `accs-sculptural-functional-20261028/`.
- **Geometric & Kinetic Primitives**: 80+ batches of mathematical knots, twisting toruses, hypercubes, gyroids, and polyhedra.
